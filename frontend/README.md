# Frontend - Next.js Chatbot UI

## Cài đặt

```bash
npm install
```

## Cấu hình

Tạo file `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

## Chạy ứng dụng

```bash
# Development
npm run dev

# Production
npm run build
npm run start
```

Ứng dụng sẽ chạy tại `http://localhost:3000`
